# iBadz app icons

Dedicated opaque app icons for favicons and mobile home screens. The in-app racket logo remains unchanged.

- favicon-32.png: browser tab
- apple-touch-icon.png: 180×180, iPhone/iPad home screen
- icon-192.png: 192×192 manifest icon
- icon-512.png: 512×512 manifest icon, with central safe area for OS masking

Created with the built-in image generation tool on 2026-11-23. Resized from the generated square master with macOS sips. No credentials or external asset dependencies.

## Generation prompt

Use case: logo-brand. Create a single finished square app icon for iBadz, a modern Thai badminton scorekeeping club app. Flat polished minimal graphic, instantly legible at tiny favicon sizes. Full bleed solid very dark blue-green background #08181e with a very subtle teal glow, no transparent margins, no rounded outer corners (OS masks icon). Center a bold striking lime #e9ff74 monogram 'iB', carefully drawn as one cohesive sporting symbol, with a small simple badminton shuttlecock motif integrated into the B negative space. Prioritize strong silhouette, thick smooth shapes, clean negative space. Keep all foreground artwork within central 68 percent for mobile safe cropping. Only text iB, no tagline, no extra words, no thin racket strings, no photographs, no mockup, no shadows outside image, no white border. Premium clean modern app icon, restrained, high contrast. 1024x1024 square.
