# Racket image assets

Both PNG assets were extracted from user-supplied badminton racket photos with background removal, preserving transparency between strings.

- `racket-cutout.png`: complete orange/grey racket, used as decoration on the score setup screen.
- `racket-head-short-shaft.png`: angled close-up head and short shaft, used in the header logo. This asset comes from the close-up photo rather than a crop of the complete racket.

The header includes a rotating text ring around the racket image. The text animation is disabled for reduced-motion users.
